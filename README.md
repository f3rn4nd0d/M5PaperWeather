
## M5PaperWeather
  **M5Paper project with weather information from Open-Meteo ***

   ![M5PaperWeather](https://github.com/f3rn4nd0d/M5PaperWeather#:~:text=IMAGE%202021-07-09%2022%3A35%3A08.jpg "M5Paper")


### Description
  Arduino project to show internal environment data and weather information from
  Open-Meteo https://open-meteo.com on the e-ink display of the M5Paper.
  Version 2.0 is set up for Grajera (Segovia) with the Casa Grajera logo and a Spanish interface.
  Edit `weather/Config.h` with your wifi, location (`LATITUDE`, `LONGITUDE`, `CITY_NAME`) and time zone.
  No API key is needed any more (OpenWeatherMap closed One Call 2.5 in June 2024).
  The software shows the following information:
  * A header with the logo, city, wifi strength and battery status
  * Sun section with sunrise, sunset and feels like temperature
  * Moon section with moonrise, moonset, moon phase name and illumination
  * Wind section with wind direction and wind speed (km/h)
  * The internal SH30 sensor data (temperature and humidity) with the current date and time
  * A hourly forecast (every 3 hours) with hour, temperature and a weather icon
  * Forecast graphs for 8 days with temperature, rain (and today's rain probability), humidity and pressure
    at sea level. The ranges of the temperature and pressure graphs adapt to the data.
  * When the wifi or the download fails, a "Sin datos del tiempo" message is shown and the M5Paper
    tries again after `RETRY_MINUTES` instead of waiting one hour.

### Logo
  The logo is stored as a bitmap in `weather/Logo.h`, generated by `scripts/make_logo.py`.
  By default it writes "Casa Grajera" with the Borel font (`scripts/fonts`, SIL Open Font License).
  To use your own logo file: `python3 scripts/make_logo.py --image my_logo.png --height 30`
  (needs `pip install pillow`).
